# Audio Processing

## Description
Small C++ audio utility library built on miniaudio for recording, playback, and simple DSP.

See `FEATURES.md` for a full list.

## Setup
- CMake 3.10+ and a C++17 compiler.
- macOS links CoreAudio frameworks via CMake.

## Build
```bash
./build.sh
```

## Test
